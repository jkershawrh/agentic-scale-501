= 5. Prove recovery
:navtitle: 5. Recover

== RUN NOW — remove pressure and re-run

[source,bash,role="execute"]
----
python3 $HOME/agentic-501/qualification-runner.py run recovery
----

Review the recovery evidence:

[source,bash,role="execute"]
----
jq '{pressure,recovery,p95:.workload.latencyMs.p95,quality:.quality.score,correlation,policy}' \
  "$HOME/agentic-501-evidence/recovery.json"
----

A responding process is not enough. The evidence must show that pressure was removed, the workload recovered, correlation is complete, quality returned, and no unauthorized action occurred.

== Checkpoint

Compare recovery with both baseline and pressure. Record whether latency and quality returned toward the reference state.
