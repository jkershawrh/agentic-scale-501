== Scale and certify a governed agentic workload

This Showroom-style lab asks one question: *what remains true when a governed multi-agent workload is placed under useful load and controlled pressure?*

The lab produces a reviewable proof package, not an automatic promotion. The current repository supports a safe *REHEARSAL* path. Live OpenShift execution, approved Intel hardware telemetry, fault injection, and Launchpad certification remain gated.

IMPORTANT: Every displayed metric in this journey is rehearsal-sourced. This content does not claim a live capacity result, approved Intel performance, or certification.

== Learning objectives

By the end, a learner can:

. distinguish functional success from a measured operating envelope;
. keep workload image, evaluation set, target, policy, model, and run correlation attributable;
. compare baseline, sustained, pressure, and recovery evidence without treating availability as success;
. fail closed when telemetry or proof is missing;
. preserve the boundary between a machine-generated recommendation and a human certification decision.

== Safe execution contract

Commands labeled *RUN NOW — LOCAL REHEARSAL* read repository files and write nothing outside the learner's own worksheet. Commands labeled *GATED FUTURE LIVE EXECUTION* are explanatory only and must not be run until every gate in xref:00-preflight.adoc[Preflight] is approved.

Start the lab from the repository root:

[source,bash]
----
node content-501/tools/rehearsal-check.mjs
----

Expected classification:

[source,text]
----
REHEARSAL ONLY — 4 contract-shaped envelopes validated; certification remains unavailable.
----

== Proof vocabulary

Every phase uses `{proof-schema-version}` and carries:

* `source`: `live`, `rehearsal`, or `offline`;
* `runId` and immutable comparison identity;
* workload, correlation, inference, policy, quality, and resource evidence;
* pressure and recovery evidence when the phase requires it;
* `automatedPromotion: false`, `humanReviewRequired: true`, and a human-owned disposition.

The proof contract is defined in `contracts/agentic-scale-proof.schema.json`. The values in `contracts/thresholds.draft.json` are deliberately unapproved and cannot certify a run.
