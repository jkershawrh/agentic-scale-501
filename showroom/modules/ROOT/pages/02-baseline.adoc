== Evidence review

Trace these joins rather than reading one headline metric:

. `runId` joins the phase to the declared run.
. `correlation.completeJourneys` accounts for every expected journey.
. `policy` shows evaluated, compliant, and unauthorized activity.
. `quality` identifies the scorer and evaluation count.
. `inference` attributes model, endpoint, latency, and token use.
. `resources` names its telemetry source; a rehearsal hardware label is not approved hardware proof.
. `authority` preserves human review and disables automated promotion.

=== Review lens

* *Identity:* the declared image, evaluation set, target, model, policy, and scorer.
* *Completion:* expected journeys equal completed and correlated journeys.
* *Usefulness:* quality and task outcomes remain visible beside latency.
* *Safety:* policy evaluation and unauthorized actions are explicit.
* *Inference:* endpoint, model, tokens, and latency remain attributable.
* *Resources:* the telemetry source is named and source-admitted.
* *Authority:* the runtime recommends; a human decides.
* *Limits:* rehearsal measurements cannot establish destination capacity.
* *Review:* unresolved fields are carried forward, not silently defaulted.

== Learner checkpoint

Record the baseline p95 journey latency, inference p95, quality score, policy compliance, correlation ratio, and source. Add the sentence: “These are rehearsal fixture values, not observed OpenShift or Intel performance.”

*Pass when:* your baseline note includes source and provenance, not just performance numbers.

== Verify

Confirm that expected and completed journeys match, every journey has a correlation identifier, and no unauthorized action is present. Capture the p50 and p95 journey latency separately from inference latency so later queueing is visible rather than hidden in one aggregate.

Verify that the model, endpoint, evaluation set, workload image, target, policy, and telemetry source match the declaration. Mark any missing field as inconclusive. Do not copy the rehearsal CPU label into a statement about observed Intel utilization.

Record the quality score, policy-compliance ratio, token counts, error count, timeout count, and reviewer state. This creates the reference against which every later phase must be compared.

== Key takeaway

A baseline is a correlated reference state, not a single latency number. It must preserve identity, usefulness, policy, resource provenance, and human authority together.
