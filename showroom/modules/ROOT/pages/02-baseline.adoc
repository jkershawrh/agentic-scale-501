= 2. Establish a baseline
:navtitle: 2. Baseline

== RUN NOW — execute the reference workload

[source,bash,role="execute"]
----
node content-501/tools/qualification-runner.mjs run baseline
----

Inspect the measurements you created:

[source,bash,role="execute"]
----
jq '{phase,source,concurrency:.profile.concurrency,workload,correlation,quality,policy,authority}' \
  "$HOME/agentic-501-evidence/baseline.json"
----

This is an observed participant-process baseline, not a production benchmark. Record its p95 latency, quality, and correlation ratio in `learner-decision.md`.

== Checkpoint

You pass when four journeys completed, correlation is complete, unauthorized actions are zero, and the source remains `offline`.
