= 4. Apply controlled pressure
:navtitle: 4. Pressure

== Safety boundary

The runner applies only a bounded latency delay inside its own local journey execution. It cannot delete pods, change cluster resources, call a shared model, or affect another participant.

== RUN NOW — cross one named boundary

[source,bash,role="execute"]
----
node content-501/tools/qualification-runner.mjs run pressure
----

Inspect the effect:

[source,bash,role="execute"]
----
jq '{condition:.pressure.condition,admitted:.pressure.admitted,removed:.pressure.removed,p95:.workload.latencyMs.p95,quality:.quality.score,errors:.workload.errorCount,unauthorized:.policy.unauthorizedActions}' \
  "$HOME/agentic-501-evidence/pressure.json"
----

Compare p95 with sustained load. Pressure should be visible, attributable, and still active in this phase. Policy and correlation must remain intact.

== Checkpoint

You pass when exactly one condition is named, its blast radius is local, `removed` is false, and the proof still preserves policy and authority.
