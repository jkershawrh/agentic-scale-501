= 6. Score and make the human decision
:navtitle: 6. Decide

== RUN NOW — generate the report

[source,bash,role="execute"]
----
python3 $HOME/agentic-501/qualification-runner.py report
sed -n '1,240p' "$HOME/agentic-501-evidence/qualification-report.md"
----

The machine may recommend `REHEARSAL COMPLETE`, but it cannot certify or promote. Review the four phase rows and challenge these questions:

* Did the comparison identity remain fixed?
* Did useful work complete under sustained load?
* Was the pressure effect visible and singular?
* Did the system recover after pressure was removed?
* Were correlation, policy, and human authority preserved?
* Which production claims remain unsupported?

== RUN NOW — record your disposition

[source,bash,role="execute"]
----
sed -n '1,200p' "$HOME/agentic-501-evidence/learner-decision.md"
----

Edit that file in the Terminal or editor and select exactly one outcome: `REHEARSAL COMPLETE` or `INCONCLUSIVE`. Add at least three exact evidence paths supporting the choice.

== Checkpoint

You pass when another reviewer can reproduce your disposition without relying on an oral explanation.
