= 3. Sustain useful load
:navtitle: 3. Sustain

== RUN NOW — increase concurrency

[source,bash,role="execute"]
----
python3 $HOME/agentic-501/qualification-runner.py run sustained
----

Compare baseline and sustained evidence:

[source,bash,role="execute"]
----
jq -s 'map({phase,concurrency:.profile.concurrency,completed:.workload.completedJourneys,p95:.workload.latencyMs.p95,throughput:.workload.throughputPerMinute,quality:.quality.score,correlation:.correlation})' \
  "$HOME/agentic-501-evidence/baseline.json" \
  "$HOME/agentic-501-evidence/sustained.json"
----

Concurrency rises from one to five and the number of journeys increases. A successful phase must preserve quality, policy, correlation, and human authority—not merely produce more throughput.
