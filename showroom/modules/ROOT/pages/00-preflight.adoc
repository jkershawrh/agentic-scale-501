== Business decision

Choose a governed agent workload that must remain trustworthy as demand grows. The default scenario is a customer-support triage service preparing for a larger rollout.

== RUN NOW — create your run

[source,bash,role="execute"]
----
rm -rf "$HOME/agentic-501-evidence" "$HOME/agentic-501-evidence.tgz"
node content-501/tools/qualification-runner.mjs init \
  --scenario customer-support-triage-readiness
----

Inspect what you now own:

[source,bash,role="execute"]
----
find "$HOME/agentic-501-evidence" -maxdepth 1 -type f -print
cat "$HOME/agentic-501-evidence/qualification-profile.json" | jq
----

The profile gives your run a unique identity and preserves two authority rules: automated promotion is disabled, and a human review is required.

== Checkpoint

You pass when the workspace contains `qualification-profile.json` and `learner-decision.md`, and you can explain why the runner may recommend but cannot certify.
