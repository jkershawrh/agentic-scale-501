== Why this matters

A scale comparison is meaningless if the workload, evaluation set, target, or policy changes quietly between phases. Your generated profile freezes those identities while allowing concurrency and the single pressure condition to change.

== RUN NOW — verify the invariant identity

[source,bash,role="execute"]
----
jq '{runId,scenario,profileId,profileVersion,workloadImageDigest,evaluationSetVersion,target,authority}' \
  "$HOME/agentic-501-evidence/qualification-profile.json"
----

Write one sentence in `learner-decision.md` describing the business outcome you are protecting. Do not edit the run ID, workload digest, evaluation set, or target after execution begins.

== Stop conditions

Stop and classify the result as inconclusive if an evidence file is absent, a phase carries a different run identity, correlation is incomplete, pressure is not removed, or automated promotion appears anywhere.

== Checkpoint

You pass when you can name what stays fixed, what changes, and which condition makes the run inconclusive.
